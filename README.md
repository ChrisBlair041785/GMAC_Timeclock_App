# SDC480-Capstone-Project
GMAC - Time Clock application 

Project Requirements: 
•	The website must include at least five distinct pages.
•	You must have a back-end database containing at least five tables.
•	After week 1, the site must be hosted in the cloud.
•	Elements of secure software must be implemented.
•	Website should be accessible from any computer.
•	All data in all tables should appear as real data, and not “jibberish.”
•	Customers’ end-users should have the ability to search for and return data.
•	Customers’ end-users should have the ability to register, create, and change passwords.
•	Users’ activities should alter data – either by removing it or by adding it to your tables.
•	Your project needs to look like a “real” website because you will want to use the project as part of your portfolio to present to employers.

Description:
This project is for a small business to modernize the way they track clock in and clock out times for large number of kids they have in their afterschool martial arts program. Currently they track it via a notebook and paper, which leads to missed times, while also making it difficult for them to see who picks up “late” on regular basis, so they can adjust their billing for said students. 
My idea is to have a simple user interface that will work on both a desktop/laptop as well as a tablet, where the staff member(s) can login to access the home page.  Once on the home screen they will have the option to select from adding/removing students from the database, clocking in/out students, and running reports. The application will have 4-10 users, with possibly 2-3 concurrent users at any time. 

All the pages will be laid out in such a way that it makes it extremely user friendly, easy to use and intuitive by design. For color theming, I’m going to go with the colors of the school, which is predominantly black, white and orange. 
I plan to write the program in PHP and use MySQL as the database for it. While writing, developing and ever after deployment of the program, the files will be stored in my GitHub Repository. 

As for security the program will require a username and password to login, and there will be 2 levels of users, standard users, and admin. Standard users will only be able to use the clock in/out and reports pages, while the admins will have access to the add/remove page. 

When it comes to deployment, I’m still researching different options, as well as will be talking with the school to see if they would be willing to pick up the cost of hosting, if that’s the only reasonable option. The other option which could work for them is to run it locally on a computer, eliminating the need for website hosting, but by running it this way would remove their ability to use the tablet and be mobile, which I know is probably going to be a big want for them, since they are always having to get up from the desk to go call for the kids. Overall, this will have to be a conversation I have with them when I present them with the application.
